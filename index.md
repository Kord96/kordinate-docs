# Kordinate

Coordinate specialized AI agents into a team — with kords, guards, and a recall system.

- **[Guards](framework/guards.md)** — hook-based enforcement that only the right agent performs protected operations
- **[Kords](framework/kords.md)** — defined protocols between agents for sharing expertise
- **[Subagent P2P](agents/beorn.md)** — subagents can invoke other subagents at any depth
- **[Recall System](framework/memory.md)** — knowledge properties and registry on top of the runtime's native memory
